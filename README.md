## What is this?

A full-featured PHP single-vendor e-commerce site. One store owner manages all products; customers browse, add to cart, and checkout. Includes a full admin panel for inventory and order management.

## 🚀 Setup

1. Import DB schema from `db/`
2. Configure connection in `config.php`
3. Deploy to PHP + MySQL host
